# DevOps Capstone Project

[![CI Build](https://github.com/Angelina0204/devops-capstone-project/actions/workflows/ci-build.yaml/badge.svg)](https://github.com/Angelina0204/devops-capstone-project/actions/workflows/ci-build.yaml)

## Project Overview

The DevOps Capstone Project develops an Account REST API
microservice for managing customer account information.

## Features

- Create customer accounts
- Read account information
- Update customer accounts
- Delete customer accounts
- List customer accounts
- Automated testing and code quality checks
- Continuous integration using GitHub Actions
- Containerization using Docker
- Deployment using Kubernetes

## Technologies Used

- Python
- Flask
- REST API
- Nose
- Flake8
- GitHub Actions
- Docker
- Kubernetes
- Tekton

## Purpose

This project demonstrates the software development lifecycle
using DevOps practices, automated testing, continuous
integration, containerization, and deployment automation.
